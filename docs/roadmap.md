# Yol Xəritəsi (docs/roadmap.md)

### Mərhələ 1: Texniki audit və pilot layihə (1–2-ci aylar)
- Nazirlik ekspertləri və aqronomlarla torpaq qiymətləndirmə modelinin verifikasiyası;
- 1 pilot rayonda (Füzuli rayonu) 15–20 real torpaq sahəsi üzərində sınaq müsabiqəsi;
- ASAN Login və EKTİS test mühitlərinə birbaşa inteqrasiya.

### Mərhələ 2: Arxitektura miqrasiyası və real peyk/torpaq məlumatları (3–5-ci aylar)
- PostgreSQL + PostGIS geoverilənlər bazasına keçid;
- ISRIC SoilGrids qlobal torpaq xəritələri və Copernicus DEM yüksəklik modellərinin inteqrasiyası;
- Sentinel-2 peykləri vasitəsilə 10 metrlik real NDVI vegetasiya monitorinqi;
- ANAMA-nın rəsmi mina sertifikatları reyestri ilə avtomatlaşdırılmış inteqrasiya.

### Mərhələ 3: İnvestisiya və maliyyə ekosistemi (6–9-cu aylar)
- Sahibkar üçün avtomatlaşdırılmış ROI və gəlirlilik kalkulyatoru;
- Kənd Təsərrüfatı Kredit və İnkişaf Agentliyi (AKİA) subsidiyaları və güzəştli kreditlərin inteqrasiyası;
- İnvestor və sahibkar arasında təhlükəsiz birbaşa rabitə və sənəd mübadiləsi;
- Region üzrə kənd təsərrüfatı texnikası və aqrotexniki avadanlıqların birgə istifadəsi (equipment sharing) modulu.
