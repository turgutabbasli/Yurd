# Məlumat Mənbələri və Təhlil Hesabatı (docs/data-report.md)

"Yurd" portalında istifadə olunan aqroekoloji, geodinamik və inzibati məlumatların mənşəyi aşağıdakı kimidir:

| Göstərici | Metod və Mənbə | Nişan | Təsvir |
|---|---|---|---|
| **İqlim (Temperatur, Yağıntı, Günəş radiasiyası)** | NASA POWER API (Kənd təsərrüfatı iqlimi) | **Həqiqi** | Rayonların mərkəz və kənd koordinatları üzrə vegetasiya dövrü (aprel–oktyabr) orta temperaturu və illik yağıntı göstəriciləri. |
| **Torpaq kimyası (pH, Üzvi karbon, Azot)** | Qarabağ və Şərqi Zəngəzur üzrə aqrokimyəvi təhlillər | **Nümunə məlumat** | Lowland (isti, neytral pH 6.8-7.5) və dağlıq yaylaqlar (turş/zəif turş, yüksək üzvi karbon) üzrə paylanmış dəyərlər. |
| **Torpaq mexaniki tərkibi (Gil, Qum, Toz)** | Aqrofiziki təsnifat | **Nümunə məlumat** | Bitkilərin kök sisteminə uyğun gilli-qumsal və gillicəli torpaq nisbətləri. |
| **Relyef və Yamac bucağı** | DEM hündürlük modeli | **Nümunə məlumat** | Lowland düzənlikləri (< 2°), dağətəyi (3-6°) və yüksək dağ yamacları (> 7-12°). |
| **Su və Yol məsafələri** | Xəritə ölçmələri (Köndələnçay, Bərgüşad, Həkəri, Xaçınçay, Araz) | **Nümunə məlumat** | Ən yaxın magistral yola və daimi su anbarı/çayına olan real təxmini məsafələr. |
| **Vegetasiya indeksi (NDVI)** | Sentinel-2 multispektral peyk müşahidəsi | **Nümunə məlumat** | 2018–2025-ci illər üzrə dinamika. |
| **Mina təmizlənməsi statusu** | ANAMA təsnifatı modeli | **Simulyasiya** | Təmizlənmiş və gözləmədə olan ərazilər (təhlükəsizlik məqsədilə heç bir uydurma məlumat verilməməsi üçün həmişə Simulyasiya nişanlanır). |
| **EKTİS reyestri** | Elektron Kənd Təsərrüfatı İnformasiya Sistemi | **Simulyasiya** | VÖEN və dövlət reyestri mübadiləsi. |
